An offline, open-source GTA 6 trophy guide and tracker: all 55 official PS5 trophies with own-words guides and named sources, a roadmap to platinum, the one missable trophy flagged, count trackers, and progress saved in your browser.

## Run it

```sh
node serve.ts
```
